Как это работает:

  • 📥 Скачать — архив .7z с курсором качается с GitHub в папку extreme_data/cursors_cache/.
  • ✅ Установить — архив распаковывается во временную папку, файлы .cur/.ani копируются в C:\Windows\Cursors\<имя>\, а пути прописываются в реестр HKCU\Control Panel\Cursors.
  • ▶️ Применить — курсор переключается без перезагрузки через SystemParametersInfo(SPI_SETCURSORS).
  • 🗑️ Удалить — папка курсора удаляется из C:\Windows\Cursors, архив — из кэша.
  • 🔄 Обновить — перечитывает список из assets/cursors.json.

Приложение требует прав администратора, потому что пишет в системную папку C:\Windows\Cursors.

Все данные хранятся портативно — в папке extreme_data рядом с программой. Удаление программы не затрагивает систему, кроме уже установленных курсоров.
